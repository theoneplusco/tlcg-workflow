# TLCG Workflow — brand tokens

Source: the `:root` variables in `index.html` (the app's own iOS-style system).

| Token | Value | Use |
|---|---|---|
| `--ios-blue` | `#007AFF` | Primary actions, links, focus rings, active states |
| `--ios-green` | `#34C759` | Success / active |
| `--ios-orange` | `#FF9500` | Warnings, admin accents |
| `--ios-red` | `#FF3B30` | Destructive, errors |
| `--ios-indigo` | `#5856D6` | Info tags |
| background | `#F2F2F7` | Page background (grouped iOS background) |
| surface | `#FFFFFF` | Cards |
| label | `#1C1C1E` / secondary `#6B7280` | Text |
| separator | `rgba(60,60,67,0.18)` | Borders |

Fonts: display `'Plus Jakarta Sans'` 600–800, body `'DM Sans'` 400–600, loaded from
Google Fonts. Both cover Vietnamese diacritics.
